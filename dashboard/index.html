🧭 Trade Compliance & Customs Analytics Control Tower

A customs & trade analytics MVP demonstrating how fragmented trading, logistics, ERP/commodity-code and trading-risk data can be consolidated into a single control tower for customs readiness, documentation compliance, HS code governance, tariff exposure and trade risk monitoring.

Portfolio disclaimer: All figures, counterparties, contracts, vessels, tariff rates and FTA schemes shown on this dashboard are synthetically generated for demonstration purposes only. This project does not use, reference, or expose any real employer data, credentials, or infrastructure, and it is not a substitute for validated customs/duty data (e.g. SAP GTS). Duty and FTA figures are illustrative proxies only and require SME validation before any business use.
Built by Hani Ihsanuddin · Synthetic data, Python (pandas) · Medallion architecture (Bronze → Silver → Gold) · Visualized with Plotly.js
